# TUNE 13

**A modern YouTube Music client with a clean, Apple-inspired interface.**

TUNE 13 is a maintained fork of [BitChord](https://github.com/kushagrasinghx/BitChord). It builds on the upstream project while developing its own product identity, Android experience, and release channel.

## Features

### Playback
- Search, browse and play music available through YouTube Music.
- Hi-Res lossless audio from a configured module source, with YouTube Music as fallback.
- Gapless playback and adjustable crossfade.
- Automix with beat-matching and tempo-stretching.
- Offline downloads with embedded metadata.
- Local music library and background playback.

### Connectivity and accounts
- Google account session support for personalized content.
- Spotify playlist integration.
- Discord Rich Presence.
- Last.fm and ListenBrainz scrobbling.
- Pluggable music sources with setup and health checks.

### Listening experience
- Animated album canvas and word-synced lyrics.
- Multiple lyrics providers.
- Dynamic artwork-driven theming and a Material 3 interface.
- Playback speed, skip silence, sleep timer and system equalizer integration.
- Bit-perfect USB exclusive output for compatible DACs.
- Playback and audio-format information for diagnostics.
